# AI Emotion & Mood Assistant

A Python-based computer vision project that uses a webcam to detect faces and provide educational mood-based feedback.


## Technologies Used

- Python
- OpenCV
- NumPy


## Note

This is an educational demonstration and the included mood classifier is based on simple image features. It is not a scientifically validated emotion-recognition system and should not be used for medical, psychological, hiring, or other high-stakes decisions.
