# AI Emotion & Mood Assistant

A Python-based computer vision project that uses a webcam to detect faces and provide educational mood-based feedback.

## Features

- Real-time webcam capture
- Face detection using OpenCV
- Simple mood classification
- Mood-based suggestions
- Session mood history
- Clean and lightweight Python structure

## Technologies Used

- Python
- OpenCV
- NumPy

## Project Structure

```text
ai-emotion-mood-assistant/
├── app/
│   └── main.py
├── requirements.txt
├── .gitignore
└── README.md
```

## Installation

```bash
pip install -r requirements.txt
```

## Run the Project

```bash
python app/main.py
```

Allow camera access when requested. Press **Q** to close the application.

## Note

This is an educational demonstration and the included mood classifier is based on simple image features. It is not a scientifically validated emotion-recognition system and should not be used for medical, psychological, hiring, or other high-stakes decisions.
